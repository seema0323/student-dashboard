# Student Dashboard

## 📌 Project Overview
Student Dashboard is a modern and responsive web application developed to help students manage and track their learning journey. It provides an interactive dashboard where students can view their courses, monitor their progress, and explore their learning activities in an organized way.

## ✨ Features
- Responsive and user-friendly dashboard interface
- Interactive course cards with smooth animations
- Course progress tracking with animated progress bars
- Dynamic icons using Lucide React
- Modern UI with gradient effects and hover animations
- Fast and optimized performance

## 🛠️ Technologies Used
- Next.js
- TypeScript
- React.js
- Tailwind CSS
- Framer Motion
- Supabase
- Lucide React

## ⚙️ Installation and Setup

1. Clone the repository:
```bash
git clone https://github.com/seema0323/student-dashboard.git
```

2. Navigate to project folder:
```bash
cd student-dashboard
```

3. Install dependencies:
```bash
npm install
```

4. Start development server:
```bash
npm run dev
```

5. Open your browser and visit:
```
http://localhost:3000
```
